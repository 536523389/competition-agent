## 创建远程仓库

打开 GitHub 新建仓库页面：

```text
https://github.com/new
```

建议填写：

```text
Repository name: competition-agent
Description: Competition Agent: 以竞赛结果为导向的竞赛项目总控 Agent
Visibility: Public
```

不要勾选初始化 README、.gitignore 或 License，因为本地仓库已经包含这些内容。

## 推送命令

远程仓库创建完成后，在当前项目目录执行：

```powershell
git push -u origin master
```

推送成功后，比赛表单中的作品链接填写：

```text
https://github.com/536523389/competition-agent
```
