# OPC 智能体大赛规则摘要

比赛：2026 智能体 OPC 创新创业大赛

当前分支：OPC 智能体赛道

信息来源：公开官网页面与 FAQ。官方未公开完整百分制评分表。

## 已知作品形态

智能体赛道采用 remio 作为官方指定工具，aApp 或 Skill 作为标准参赛作品形态。

## 已知赛道导向

OPC 智能体赛道关注：

- 基于智能体平台开发的智能体应用
- 不限行业与场景
- 侧重智能体能力
- 侧重工具调用
- 侧重自主性

## 公开提交导向

需要准备：

- 作品
- Demo
- 说明文档
- 提交材料

## 可反推评审关注点

由于官方未公开完整评分表，V1 暂按以下公开导向对齐：

- 智能体能力
- 工具调用与自主性
- 可运行作品完成度
- 场景价值
- Demo 表达
- 落地潜力
- 创新表达

## 特色奖项导向

公开特色奖项包括：

- 产业落地奖
- 创新表达奖
- 场景突破奖
- 生态共创奖
- 未来之星奖

## V1 对齐策略

Competition Agent 当前优先对齐：

- 智能体能力：能从目标推进到成果，而非单次问答。
- 自主性：Agent 默认执行，不要求用户反复输入继续。
- 场景突破：聚焦大学生竞赛项目推进，而非考研考公等泛学习场景。
- 落地潜力：可扩展到多比赛、多母项目和高校竞赛管理。
- 创新表达：用 Competition Agent builds Competition Agent 作为自举 Demo。
