# 示例比赛规则摘要

比赛：项目制竞赛示例

当前分支：示例比赛适配分支

信息来源：比赛公开规则、FAQ、提交页面和用户提供材料。

## 已知作品形态

根据目标比赛要求确定作品形态，例如项目链接、Demo、文档、代码、视频或附件材料。

## 已知赛道导向

项目制竞赛通常关注：

- 问题是否真实
- 方案是否清晰
- 作品是否可展示
- 交付物是否完整
- 论证是否可信
- Demo 是否能说明价值

## 公开提交导向

需要准备：

- 作品
- Demo
- 说明文档
- 提交材料

## 可反推评审关注点

如果官方未公开完整评分表，V1 暂按以下公开导向对齐：

- 可运行作品完成度
- 场景价值
- Demo 表达
- 落地潜力
- 创新表达
- 证明材料质量

## 特色奖项导向

如目标比赛设置特色奖项，应单独整理其偏好，例如：

- 产业落地奖
- 创新表达奖
- 场景突破奖
- 生态共创奖
- 未来之星奖

## V1 对齐策略

Competition Agent 当前优先对齐：

- 竞赛推进能力：能从目标推进到成果，而非单次问答。
- 自主性：Agent 默认执行可代理任务，不要求用户反复输入继续。
- 场景突破：聚焦大学生竞赛项目推进，而非考研考公等泛学习场景。
- 落地潜力：可扩展到多比赛、多母项目和高校竞赛管理。
- 创新表达：用 Competition Agent builds Competition Agent 作为自举 Demo。
