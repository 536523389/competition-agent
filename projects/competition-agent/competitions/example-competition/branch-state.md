# 示例比赛分支状态

母项目：Competition Agent

比赛分支：示例项目制竞赛

作品形态：根据目标比赛提交要求确定

分支用途：作为 Competition Agent 的第一个真实比赛验证场景。

## 分支目标

形成符合目标比赛要求的可提交成果。

## 当前提交包候选

- Competition Agent Skill
- 项目定义文档
- Demo 说明
- 演示视频脚本
- 补充材料
- Judge 报告

## 分支适配策略

强调：

- 智能体总控能力
- 自主执行
- 工具/Skill 调用思路
- 长期项目状态
- 评分导向 Judge
- 自举式 Demo

弱化：

- 泛 AI 创业团队叙事
- 大型平台叙事
- 复杂 Dashboard
- 多比赛调度

## 提交载体

使用 GitHub 链接作为作品提交入口，展示 Competition Agent 的项目结构、Skill 工作流和比赛适配分支。
